# Cyber Threat Prediction using Machine Learning

## Overview

This graduation project develops machine learning models for detecting cyber threats from network traffic data.

The project follows an end-to-end machine learning workflow including preprocessing, exploratory analysis, feature engineering, model training, evaluation, and prediction.

---

## Features

- Data preprocessing
- Exploratory Data Analysis (EDA)
- Feature engineering
- Multiple machine learning models
- Performance comparison
- Classification metrics
- Threat prediction

---

## Technologies

- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Seaborn

---

## Workflow

1. Data Collection
2. Data Cleaning
3. Exploratory Analysis
4. Feature Engineering
5. Model Training
6. Model Evaluation
7. Threat Prediction

---

## Model Evaluation

Performance is evaluated using:

- Accuracy
- Precision
- Recall
- F1-score
- Confusion Matrix
